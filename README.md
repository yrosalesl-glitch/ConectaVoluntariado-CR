# ConectaVoluntariado CR

## Descripción del proyecto

ConectaVoluntariado CR es una aplicación web que busca centralizar la gestión de oportunidades de voluntariado en Costa Rica, facilitando la publicación de actividades, las inscripciones y el seguimiento de las personas voluntarias.

## Avance 2 — Implementación del frontend

En este avance se desarrolló la estructura inicial de la aplicación web ConectaVoluntariado CR, incorporando las principales interfaces y funcionalidades del lado del cliente.

### Funcionalidades implementadas

- Página principal de la plataforma.
- Visualización dinámica de actividades mediante un archivo JSON.
- Filtrado de actividades por categoría.
- Mensaje informativo cuando no se encuentran actividades.
- Formulario de inscripción a oportunidades de voluntariado.
- Validación de campos obligatorios.
- Validación de correo electrónico y teléfono mediante expresiones regulares (Regex).
- Alertas de validación y confirmación mediante SweetAlert2.
- Generación de un objeto de inscripción visible en la consola del navegador.
- Diseño adaptable a computadoras, tabletas y dispositivos móviles.

### Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript
- JSON
- SweetAlert2

### Ejecución del proyecto

1. Abrir la carpeta del proyecto en Visual Studio Code.
2. Instalar la extensión Live Server.
3. Abrir el archivo `index.html`.
4. Seleccionar la opción **Open with Live Server**.

**Nota:** Se requiere ejecutar el proyecto mediante un servidor local para permitir la carga del archivo JSON.
