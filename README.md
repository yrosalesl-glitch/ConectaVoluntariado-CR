# ConectaVoluntariado CR

## Descripción del proyecto

ConectaVoluntariado CR es una aplicación web que busca centralizar la gestión de oportunidades de voluntariado en Costa Rica, facilitando la publicación de actividades, las inscripciones y el seguimiento de las personas voluntarias.
